# Laboratorio #9 · Estructuras de control en PHP

Desarrollo Web · Módulo III · Unidad II (PHP)

1. Haz **Fork** de este repositorio a tu cuenta y habilita *Actions* en tu fork.
2. Clónalo dentro de `htdocs` de XAMPP y crea tu rama: `git checkout -b lab9-apellido-nombre`.
3. Sigue el **documento del estudiante** y completa los `TODO` de `index.php` y `css/estilos.css`.
4. Haz un commit por ejercicio y `git push`.
5. Prueba localmente: `php autograde.php` (en Windows: `C:\xampp\php\php.exe autograde.php`).

El resultado oficial lo ves en la pestaña **Actions** de tu fork (resumen del job "Autograde Lab 9").
Este autograde **no envía tus datos a ningún servidor**.
